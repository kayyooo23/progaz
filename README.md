# ПРОГАЗ — тест API остатков

Для локальной проверки нужен Node.js 20 или новее. После установки Node.js откройте папку проекта и выполните:

```powershell
node server.js
```

Сайт откроется по адресу `http://localhost:8787`. Проверочный API: `http://localhost:8787/api/inventory`.

Сейчас API возвращает тестовый остаток из учебной 1С: артикул `neva-4511e`, 5 штук. В следующем этапе источник будет заменён на обмен с 1С, а внешний формат API останется прежним.
